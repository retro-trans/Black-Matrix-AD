## Changes included

- **AP-shortage reset:** `tools/psi2.py` now decodes mode-3 subcommand `0x23`
  as one expression, matching the original handler. The old two-expression
  signature swallowed the following jump and prevented its relocation.
- **Book-menu spacing:** `tools/vwf.py` resolves each glyph's live line record
  by its atlas handle instead of the stale global record pointer. Strict SH-4
  tests exercise the emitted instructions; a local capture replay corrects 82
  of the menu's 98 cell positions. Stock 17/19-cell grids remain unchanged.
- **Activity prompts:** cooking (3 AP), cleaning (2 AP), woodcutting (4 AP).
  These are System UI, not character speech; AP logic is unchanged.
- **Help graphics:** cooking and woodcutting instructions are translated in
  EVENT.DAT's existing tilemaps/texture allocations, preserving controllers,
  button colors and guide lines. `tools/hud.py` includes both in normal builds.
- **Field menu:** Save / Load / Setup, each within its fixed five-cell row.
- **Gate:** all six routes have an English confirmation and shortened player
  options, `Go outside!` / `Stay inside!`, that fit the 15-cell choice limit
  including alignment padding. Prague's question is now two rows:
  `Well? Still want` / `to go outside?`.
- Glossary IDs and UI source wording are included. See `docs/activity-ui.md`
  for asset locations, script offsets, and implementation details.
