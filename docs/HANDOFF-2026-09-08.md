# Handoff — 2026-09-08: stock Flycast HD text and stage titles

## Current result

The active experiment is `tools/hd_ui/run_stock_atlas.cmd`, not the older
custom-Flycast `run.ps1`. Revision 11 uses unchanged stock Flycast with
game-side canonical font atlases and standard PNG replacements. Bizin Gothic
is rasterized with its own proportions, baseline and spacing, including the
native fallback. See [stock font atlas details](stock-font-atlas.md).

The merge preserves the other PC's 33-column wrapping fixes and 18px dialogue
row pitch. Its normal native-font generator and bundled OFL Bizin TTF remain;
the HD experiment overrides only its own English font/metrics with the newer
natural-proportion 16px model. The stronger atomic main-menu installer is
shared by both builds. Both chapter cards use `chapter_cards.py`; the older
Chapter-1-only `chaptercards.py` remains as a historical alternative, not a
second overlapping build step. Pandora's Garden remains the current preferred
title, with Pandora's Miniature Garden retained as an allowed glossary alias.

Main and battle menus have expanded English labels; the stance menu reads
Guard / Evade / Counter. Seven stance-help pages are translated. The deployment
heading is a separate standard texture replacement. Original hardware and
uncaptured UI screens still require testing. The merged suite passed 84 tests
with two optional skips. The full normal build and isolated revision 11 build
succeeded; all five embedded disc payloads matched their generated files,
including EVENT.DAT with both stage-title screens. The pre-existing backlog
of 93 overlong choice labels remains; it is not fixed by this merge.

## Stage-title screens are source-controlled

`tools/chapter_cards.py` and `script/ui/chapter_cards.tsv` implement both the
Chapter 1 ending (Pandora's Garden) and Chapter 2 opening (Golgotha Prison).
`tools/hud.py` calls the generator; `tools/build.py` includes its EVENT.DAT
output in the disc. Pulling source alone does not update an already-built
disc or an emulator save state. Rebuild the base translated disc before
creating a fresh HD test disc on the other PC.

The generated previews `build/chapter1-end-english.png` and
`build/chapter2-open-english.png` can verify that stage titles were built.
Original game files, derived graphics, disc images, VMUs and captures are
deliberately ignored by Git. They must not be force-added.

## Reproduce on another Windows PC

1. Pull `main` and follow the existing extraction/setup instructions in
   [the earlier handoff](HANDOFF-2026-09-07.md). Supply your own original game
   files in `extracted/` and an independent disc copy in `build/disc/`.
2. Install Python with Pillow and the existing build dependencies. Install
   the stock pack helper dependency with
   `python -m pip install -r tools/hd_ui/requirements-stock.txt`.
3. Run `python tools/build.py`. This includes the stage-title graphics;
   `--no-inject` generates payloads but does not update the disc.
4. Run `python tools/hd_ui/font_style.py` to verify the checksum-pinned Bizin
   font and license bundled in Git under `assets/fonts/bizin-gothic/`.
   Downloading is only necessary if those files are missing. The font is not
   installed system-wide.
5. Close any emulator using the target test disc. Stock test setup currently
   expects your normal Flycast installation at `D:/Program/FlyCast`.
   Run `python tools/hd_ui/prepare_stock_atlas.py` to create the isolated
   revision 11 disc/profile. Never copy stale ignored build files over it.
6. Run `tools/hd_ui/run_stock_atlas.cmd`. Cold-boot with a normal VMU save,
   not an emulator save state containing an older executable/font.

On a fresh PC, local texture captures are absent. Open a translated help or
dialogue page to dump the new canonical sheets, then run
`python tools/hd_ui/stock_atlas_pack.py`. For the deployment heading, show
that screen and run `python tools/hd_ui/deployment_heading_pack.py`.
Fully restart Flycast after installing PNGs. These are setup/capture steps,
not commands required on every launch. Existing verified old captures can
seed the new font pack offline via `seed_bizin_pack.py`; they are not required
on a fresh PC. The user handles game navigation.

For verification: `python -W ignore -m unittest discover -s tests -p "test_*.py"`.
Tests needing original assets or optional captured RAM may skip when those
local fixtures are absent. Do not describe a skipped visual check as passed.
